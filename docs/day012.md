Build an AI-Ready QE Repository
===============================
I establish repository-level AI instructions so that generated automation follows our QE architecture, locator standards, synchronization strategy, test-data principles and security rules.

The AI Context Hierarchy
    Repository
    │
    ├── Architecture
    │
    ├── Coding Standards
    │
    ├── AI Instructions
    │
    ├── Existing Page Objects
    │
    ├── Fixtures
    │
    ├── API Clients
    │
    └── Tests
            │
            ↓
           AI

    Without context, Duplication is the biggest risk.
